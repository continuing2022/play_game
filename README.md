# 墨影 · 古风决斗（v0.1）

一个 2.5D 一对一格斗游戏：在庭院地面上四向移动（W/S 控制前后纵深），东方古风 + 火影式的高速爽快打斗，完全用原生 Canvas 2D 写成，零依赖、零安装、零构建。

## 怎么玩

**方式一（最简单）**：双击 `index.html`，在浏览器里打开。

**方式二（本地服务）**：在本目录执行

```bash
python3 -m http.server 8123
```

然后浏览器打开 <http://127.0.0.1:8123/>。

进入主菜单后：

- 按 `1` 或 `Enter`：单人对战 AI
- 按 `2`：同一键盘双人对战
- 鼠标点击菜单按钮也可以

## 操作

| 动作 | P1 | P2 |
| --- | --- | --- |
| 移动（四方向） | `A` / `D` 左右 · `W` / `S` 前后 | `←` / `→` 左右 · `↑` / `↓` 前后 |
| 格挡 | `Q` | 右 `Shift` |
| 连斩（三段） | `J` | `M` |
| 剑气（远程） | `K` | `,` |
| 残影步（瞬身） | `L` | `.` |
| 万剑归宗（内力满） | `U` | `/` |
| 替身术（被击打时脱身） | `I` | `N` |
| 开关声音 | `B` | |
| 返回主菜单 | `Esc` | |

> 现在没有跳跃：`W` / `S`（P2 为 `↑` / `↓`）让角色在庭院里前后走动，靠上显示得更小、靠下显示得更大。出招方向仍然由左右决定：按住 `A`/`D`（P2 为 `←`/`→`）时角色朝该方向转身，普攻、剑气、残影步都朝这个方向放；松手站定会自动面向对手。角色脚前的小箭标就是当前出招朝向。
>
> 前后错开超过一个身位时，近身攻击会落空；剑气和残影步只命中同一纵深附近的对手，记得先用 W/S 调整站位。

## 核心机制

- **2.5D 纵深**：角色可以在庭院地面四向移动，前后位置会影响透视大小和前后遮挡；近身攻击、剑气和残影步都要求大致处于同一纵深，靠 W/S 走位可以躲招。
- **血条 1000**，单局 90 秒，血空即 K.O.，时间到血多者胜。
- **技能栏**：血条下方常驻 5 格技能（连斩 / 剑气 / 残影步 / 万剑归宗 / 替身术）。就绪时亮起，冷却中整体压暗并显示剩余秒数（剑气 2.5s、残影步 2.8s、替身术 6s），底部长条是冷却/内力进度；万剑归宗显示内力百分比，满内力时呼吸发光并标「可释放」，施放时标「释放中」；替身术需 20 内力且被击打时才可用。1P 模式下玩家一侧显示按键，AI 一侧只显示状态。
- **内力槽**：打人 / 被打都会攒，攒满 → 按大招键放「万剑归宗」（全屏剑雨 + 闪白 + 震屏 + 定格）。
- **替身术（I / N）**：被击打、被击倒、倒地时**唯一**能做的事——受击硬直里按攻击/移动一律无效，只有替身可以脱身。消耗 20 内力、冷却 6 秒：原地留下木桩，瞬身到对手背后，并带 0.55 秒无敌，之后恢复操作。
- **连击保护（时间设定）**：连续被击打约 **1.5 秒**（两次命中间隔不超过 1 秒，按受击/硬直时间累计）会自动挣脱：获得 0.9 秒护体无敌、把对手震开、连击中断。头顶出现「护」字就说明快触发了。
- **三段连斩**：`J` 连按可接成三段，第三段把对手击倒（可追打）。
- **残影步**：瞬身穿过对手，穿身造成伤害，附带无敌帧和残影。
- **格挡**：按住格挡键减伤 86%，但仍会掉少量血。
- **AI 对手**：会四向走位、接近、连斩、放剑气、格挡、残影步，被连击时会用替身脱身，血少时会更凶。

## 开发备注

- 纯静态项目，改完 JS 刷新浏览器即可。
- 换背景：直接替换 `assets/background.webp` 即可（建议 16:9，1280×720 以上），无需改代码。
- 手感数值集中在 `js/fighter.js` 顶部：`SUB`（替身：耗内 20 / 冷却 6s / 无敌 0.55s / 瞬身距离 120）与 `COMBO_GUARD`（连击保护：间隔窗口 1s / 触发时间 1.5s / 护体 0.9s），想调「被打多久才保护」直接改这两个常量即可。
- 冒烟测试不需要浏览器：

```bash
node test/smoke.js
```

- 画面自检用的隐藏参数（正常玩不会用到）：
  - `?demo=6&still`：AI 自动对打 6 秒后定格
  - `?scenario=ult`：直接摆出「万剑归宗」瞬间
  - `?scenario=skills`：定格展示技能栏冷却 / 内力，以及「按住左右方向朝该方向出招」
  - `?scenario=sub`：定格「替身术」瞬间（木桩 + 瞬身到对手背后）
  - `?scenario=guard`：定格「连击保护」触发瞬间（护体气罩）
