# 战斗执行优化

本文是设计说明，不改代码。它只规定现有一对一对局里四类进攻的执行：普攻三段（横斩、撩剑、崩山）、剑气、残影步、万剑归宗。

画面继续水墨剑意，只用 Canvas 程序绘制和 WebAudio 合成音效。不新增精灵图、序列帧或外置音效。

## 非目标

这份说明不引入跳跃、第二套角色、取消表、弹反或投技。替身术和格挡自身的发动条件、内力消耗、冷却保持不变。格挡减伤仍是伤害的 14%（四舍五入，至少 1 点）。血量 1000、对局 90 秒、内力满 100 后放大招，这些都不改。

演出强度按招式档位取，不再用「伤害 ≥ 66 就算重击」这一条现有判断。剑气和残影步的伤害会高于 66，但它们不是打飞档。

## 五档力度

顿帧、击退、墨线粗细、墨点数量和镜头都按档递增。连斩的第三段从第 2 档直接跳到第 4 档。

| 档 | 动作 | 命中时玩家应看到的 |
|---|---|---|
| 1 | 横斩 | 短弧，轻顿帧，击退很小 |
| 2 | 撩剑 | 弧更长，击退看得见 |
| 3 | 剑气、残影步 | 同一力度，画面分开。都不打飞 |
| 4 | 崩山 | 近身重击，普攻和技能里唯一的打飞倒地 |
| 5 | 万剑归宗的终结 | 最大伤害、最长硬直、最大镜头。落剑只是轻击 |

第 3 档内部用位移区分：剑气把人推开，残影步把人留在身边。

## 三种结果

每一种进攻都要写出挥空、命中、被挡。替身躲开时，攻击打在留下的木桩上，走挥空：没有顿帧，没有伤害数字，没有墨爆。替身术自己的现身效果保持现状。

| 结果 | 画面 | 结算 |
|---|---|---|
| 挥空 | 轨迹走完。没有顿帧，没有墨爆 | 不掉血 |
| 命中 | 该档的顿帧、击退、墨爆和飘字 | 该档伤害。只有崩山和万剑归宗的终结造成击倒 |
| 被挡 | 同一条轨迹，墨爆收成擦墨，顿帧更短，飘字为格挡 | 伤害的 14%。不击倒，不给该档的最大镜头 |

被挡的顿帧低于同档命中，格挡音用现有合成音，音量随档位略增。

## 普攻三段

段数、衔接和输入缓冲保持现状。横斩接撩剑，撩剑接崩山。前摇、持续帧、后摇不改。

| | 横斩（现况 → 目标） | 撩剑 | 崩山 |
|---|---|---|---|
| 伤害 | 46 → 40 | 58 → 56 | 92 → 104 |
| 受击硬直 | 0.22 → 0.16 秒 | 0.26 → 0.22 秒 | 0.44 秒，并进入打飞倒地 |
| 击退 | 130 → 70 | 180 → 150 | 330 → 360，打飞 |
| 命中顿帧 | 与轻击共用 0.05 → 0.04 | 0.05 → 0.06 | 重击 0.085 → 0.11 |
| 被挡顿帧 | 0.016 | 0.020 | 0.028 |
| 挥空 | 短弧挥完即收 | 弧比横斩长 | 重斩挥完，没有爆点，没有镜头 |

墨线宽度和墨点数量按 1、2、4 档递增。崩山命中时镜头推到 1.06，震屏 16。横斩和撩剑不推镜头，只给本档震屏（4 和 7）。

被挡时三段都不打飞。崩山被挡的减伤为 `round(104 × 0.14) = 15`。

## 剑气

仍是一条向前飞的墨线，速度 830、冷却 2.5 秒、最长飞行 1.7 秒，这些不改。命中或被挡都在接触点结束，墨线不再往前飞。飞出画面或超时则散成少量墨点，没有顿帧。

| | 现况 | 目标 |
|---|---|---|
| 伤害 | 88 | 72 |
| 受击硬直 | 0.30 秒 | 0.26 秒 |
| 击退 | 240 | 230 |
| 命中顿帧 | 因伤害 ≥ 66 被当成重击，0.085 | 0.08，第 3 档，不打飞 |
| 被挡顿帧 | 0.022 | 0.024 |
| 镜头 | 随重击震屏 | 命中时镜头 1.03，震屏 10。被挡不推镜头 |

命中是单点墨爆，墨点多于撩剑、少于崩山。被挡时墨线在接触处收成擦墨，减伤为 `round(72 × 0.14) = 10`。

纵深判定保持 `|Δy| ≤ 58`。

## 残影步

现在的残影步是约 0.22 秒的高速滑步，身体相交才命中，滑步期间无敌约 0.29 秒。改为短消失后再出现。

1. 消失 0.12 秒。这段时间角色不画本体，原地留一枚淡出的残影。无敌只覆盖这 0.12 秒。
2. 出现在对手靠近自己的一侧，距对手约 76 像素，纵深与对手对齐。不绕到背后，也不因为这一击改变左右命中关系。
3. 出现的同一刻打出一击。打中则用第 3 档命中。对手当时无敌或已经倒地，仍落到预定点，这一击走挥空，在落点收招。
4. 冷却保持 2.8 秒。

| | 现况 | 目标 |
|---|---|---|
| 伤害 | 66 | 72 |
| 受击硬直 | 0.38 秒 | 0.26 秒 |
| 击退 | 90 | 50 |
| 命中顿帧 | 0.085（被当成重击） | 0.08 |
| 被挡顿帧 | 0.022 | 0.024 |
| 无敌 | 滑步全程约 0.29 秒 | 仅消失的 0.12 秒 |

伤害和顿帧与剑气相同。击退明显更小，把人留在身边。命中时墨爆与剑气同级，另外在消失点和出现点各有一圈墨环。被挡减伤同样是 10，不打飞。

## 万剑归宗

三拍的时长保持现状：蓄力 0.9 秒，落剑 1.25 秒，收招 0.4 秒。施法者在这期间的无敌保持现状。落剑间隔保持约 0.115 秒，现有实现在落剑阶段大约打出 10 下。

### 蓄力

没有攻击判定。保留聚气声、轻微震屏和施法者身上的墨气。

### 落剑

落剑不再把对手锁进受击，也不再把速度清零后一直按住。每一击走正常的挥空、命中、被挡。

| 对手状态 | 结果 |
|---|---|
| 正在格挡 | 第 5 档的轻擦墨，顿帧 0.01 秒。不扣血，不击退 |
| 没有格挡 | 伤害 8，硬直 0.07 秒，击退 0，顿帧 0.012 |
| 人不在剑雨里 | 这一剑挥空，只有落墨，没有顿帧 |

0.07 秒硬直短于 0.115 秒的落剑间隔，所以剑雨中途来得及按住格挡，下一剑就走被挡。落剑不触发打飞，也不推大镜头。

现况每下 32，且直接扣血、不经过格挡。10 下就是 320，再加上终结的 72。目标里 10 下命中共 80，只占大招伤害的小头。

### 终结

落剑阶段结束后结算一次。这是第 5 档。

| | 现况 | 目标 |
|---|---|---|
| 伤害 | 72，且不看格挡 | 命中 200；被挡 `round(200 × 0.14) = 28` |
| 命中 | 短硬直，击退 260，震屏 18，镜头回到 1 | 击倒，顿帧 0.14，震屏 24，镜头推到 1.12 |
| 被挡 | 不会发生 | 擦墨，顿帧 0.03，不击倒，镜头不推到 1.12 |

一次打满、全程不格挡的大招约为 `10 × 8 + 200 = 280`。低于现在大约 392 的总伤害，因为原来的伤害主要在无法格挡的落剑上。这个下降是预定的：大伤害只留在终结上。

## 目标数值一览

顺序：横斩 < 撩剑 < 剑气 = 残影步 < 崩山 < 大招终结。

| 动作 | 伤害 | 击退 | 命中顿帧 | 被挡伤害 |
|---|---|---|---|---|
| 横斩 | 40 | 70 | 0.04 | 6 |
| 撩剑 | 56 | 150 | 0.06 | 8 |
| 剑气 | 72 | 230 | 0.08 | 10 |
| 残影步 | 72 | 50 | 0.08 | 10 |
| 崩山 | 104 | 360，打飞 | 0.11 | 15 |
| 落剑，每下 | 8 | 0 | 0.012 | 0 |
| 大招终结 | 200 | 击倒 | 0.14 | 28 |

音效继续实时合成。挥空只有出招声。命中音的音量和低频随档位增加。被挡用格挡声。终结用现有重击声，音高更低、更响。

## 验收

实现后应能直接看出这些差别：

1. 横斩、撩剑、崩山的弧长、顿帧和击退一档比一档明显。只有崩山把人打飞。
2. 剑气和残影步的伤害、顿帧、墨爆同级。剑气把人推开，残影步把人留在身边。两招都不打飞。
3. 残影步先消失再出现在对手身侧。无敌只在消失的 0.12 秒里。出现在背后的情况不发生。
4. 挥空没有顿帧和伤害数字。被挡是擦墨和约 14% 的伤害。替身木桩上的攻击没有命中爆点。
5. 大招蓄力不掉血。落剑中途按住格挡后，后续落剑不扣血。终结被挡只掉 28，并且没有 1.12 的镜头。
6. 全程不格挡时，大招的主要掉血发生在终结，而不是落剑。
7. 仍是程序绘制和合成音效，没有新的图片或音频文件。
